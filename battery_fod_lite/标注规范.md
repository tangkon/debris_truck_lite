# 标注规范 —— battery_fod_lite（给标注员 / 数据负责人）

> 本规范决定模型能学到什么。口径一旦中途变更，必须整批重标，不要混用两套口径。
> 尺寸阈值的来龙去脉见《技术方案.md》§5。

---

## 1. 类别与目录格式

- **单一类别** `foreign`（id=0）。石子、螺栓、螺母、煤块、金属屑……全部标为同一类。
  标注工具若输出 `label=1`，`train.py prepare --remap 1:0` 会自动映射，无需人工改。
- 目录结构（YOLO 标准）：

  ```
  <src>/
    images/  a.jpg b.jpg ...        （原始分辨率即可，2560x1440 / 1920x1080 都收）
    labels/  a.txt b.txt ...        （每行: cls cx cy w h，归一化 0~1）
  ```

- 一张图里可以有 0~N 个框；**没有任何异物的图也要交**（空标签文件），它们是负样本。

---

## 2. 框的画法

1. **紧包框**：框的四边贴住异物可见轮廓，不要留"安全感"边距。
   框偏大 = 尺寸口径偏大 = 门控把 4mm 当成 5mm 放行，直接污染业务口径。
2. **轴对齐矩形**（YOLO txt 天然是轴对齐的）。斜放的长条异物，框住它的外接矩形即可，
   尺寸口径按**框的长边**算（与 detect.py 的 `size_mm = max(w,h) * mm_per_px` 一致）。
3. **只标"停留在上盖表面"的异物**。夹具上、边框上、背景地面上的异物不标。
4. 一个异物一个框；粘连成团的一堆按一团标一个框（业务按"一处异物"处置）。

---

## 3. 尺寸截断：标到 4mm 为止（本规范的核心数字）

- **标**：所有你看得见的、**估计 ≥4mm** 的颗粒状异物（石子/螺栓/螺母/煤块/金属屑）。
  4–5mm 这一档**必须标**——它们是训练缓冲带，让模型在 5mm 业务阈值处的置信度干净
  （推理侧门控会把 <5mm 的检出丢弃，标了不会造成现场误报）。
- **不标**：估计 <4mm 的微小颗粒。它们低于本档位可稳定学习的尺寸，
  标了只会引入标签噪声（`prepare --min-mm 4.0` 也会把它们清洗掉）。
- **怎么估 4mm**：mm/px=0.8 时 4mm ≈ 原生 5 像素。标注界面放大到 400% 以上，
  用像素尺量长边：≥5px 才标。数据负责人每周抽 20 张复核这个边界。
- **业务口径仍是 5mm**：对外承诺"检 ≥5mm"。4mm 只是标注/训练截断，不对外。

---

## 4. 灰尘 / 污渍 / 锈迹：一律不标为异物

- **平面状**的灰尘层、水渍、锈斑、油污 → **不标**（它们不是颗粒异物）。
- **有立体感**的团聚物（灰团里嵌着颗粒、结块凸起）→ 标。
- 判别口诀：**"有影子、有边缘高光、放大看是颗粒"才标；"只是一片颜色"不标。**
- 同时：**多交"有灰尘但无异物"的空标签图**（数据侧建议占总量 ≥15%，越多越好）。
  管线在切片阶段会按 `--keep-empty-ratio 0.15` 对纯背景切片下采样以平衡正负比例——
  数据侧空图不够时，下采样后剩下的背景切片就不足以压住灰尘误报。
  这是压误报最有效的手段。

---

## 5. 负样本与多样性

- 空标签图要覆盖：干净盖面、厚灰尘盖面、强光斑、阴影、不同包型、不同摆放位置。
- 每种"容易误报"的场景（锈缝、警告标签、盖板筋线、螺栓排）都要有对应的空标签图。
-  train/val/test 切分由 `prepare --ratios 0.8 0.1 0.1` 完成，标注侧不用管，
   但**同一包型/同一天的图不要人为集中交**，避免切分后某 split 分布偏斜。

---

## 6. （二期可选）ROI 掩膜标注

若现场实测背景误报率高、决定启用静态掩膜（《技术方案.md》§9），追加两类**多边形**标注：

- `pack_top`：上盖可见表面（实例级，同框几个包标几个实例）。
- `fixture_frame`：托盘框架、包间缝、夹具等"永远不算表面"的区域。

多边形贴表面边界画；锈缝必须划进 `fixture_frame`，不许划进 `pack_top`。
（一期不标，先跑通主链路。）

---

## 7. 交付出检清单（数据负责人逐条勾）

- [ ] 每张图都有对应 txt（无异物 = 空文件），无孤儿文件。
- [ ] 类别 id 全为 0（或 1 且已确认 remap 配置）。
- [ ] 抽查 20 张：框贴边、无"安全感"边距、无漏标可见颗粒（≥4mm）。
- [ ] 抽查 20 张：灰尘/污渍/锈迹没有被标成异物。
- [ ] 空标签图占比 ≥15%，且覆盖灰尘/光斑/阴影/多包型。
- [ ] 4–5mm 边界样本有标（每周复核记录在案）。
- [ ] 尺寸口径变更记录：本规范版本号 + 变更日期（口径变更 = 整批重标）。
